Sim-to-Real Chessboard State Prediction

This project trains a chessboard square classifier primarily on synthetic images rendered in Blender, and evaluates how well it generalizes to real chessboard images. We study generalization from synthetic to real data by measuring: (1) zero-shot performance (no real data in training), (2) fine-tuned performance (small real dataset), and (3) combined training (synthetic + real).

Project Goal

Given a single RGB image of a chessboard, the model predicts the piece class for each of the 64 squares. The per-square predictions are combined into a full board state, converted into a FEN string, and visualized as a chessboard image.

Constraints: the model uses a single static image (no temporal information), and occlusions are not explicitly labeled.

Pipeline

Step 1: Synthetic → Prediction

Synthetic images are rendered using Blender/PyBlender.

Step 2: Real → Sim-to-Real Transfer

We evaluate zero-shot transfer on real images, then fine-tune using a small real dataset, and finally train on a combined synthetic+real dataset for best overall performance.
